How FLAMES Works

FLAMES is a traditional name game played for fun. It uses a simple letter-counting method to land on one of six relationship categories.

  1. 1

    Enter two names

    Type your name and another name.

  2. 2

    Match common letters

    Letters that appear in both names cancel each other out.

  3. 3

    Count remaining letters

    The unmatched letters from both names are counted together.

  4. 4

    Count through F-L-A-M-E-S

    Starting at F, count around the word "FLAMES" using the count.

  5. 5

    Eliminate letters

    Each pass removes one letter. Repeat until one remains.

  6. 6

    The final letter determines the result

    One of Friends, Love, Affection, Marriage, Enemies, or Siblings.

The Categories

  • F 🤝 Friends
  • L 💕 Love
  • A 💛 Affection
  • M 💍 Marriage
  • E ⚡ Enemies
  • S 👨‍👩‍👧 Siblings

FLAMES is a traditional game for fun and does not measure real compatibility.
